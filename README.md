# Stick Wars: Duel ⚔️

لعبة استراتيجية 2D لمباراة خاصة بين لاعبين، باستخدام Phaser وFirebase Realtime Database.

## تشغيل اللعبة
1. فعّل Anonymous في Firebase Authentication.
2. أنشئ Realtime Database في مشروع Firebase.
3. ضع قواعد قاعدة البيانات الموضحة في تعليمات المشروع.
4. فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).

لا تحتاج اللعبة إلى Node.js أو Render أو سيرفر Socket.IO؛ Firebase يتولى تسجيل الدخول ومزامنة الغرف واللعب.

## طريقة اللعب
- اللاعب الأول ينشئ غرفة ويرسل الكود المكوّن من 6 رموز.
- اللاعب الثاني يدخل الكود، وتبدأ المباراة تلقائيًا.
- كل لاعب يدرب وحداته من رصيده، والذهب يزيد تلقائيًا.
- اللاعب الأول يدير دورة المحاكاة المشتركة، وتُزامَن حالة المباراة عبر Realtime Database.

## ملاحظات
هذه نسخة أولية قابلة للتجربة. Firebase Spark مجاني ضمن حدود الاستخدام والحصص، وليس غير محدود. لا تضع مفاتيح Service Account أو بيانات خاصة في ملفات الواجهة.
