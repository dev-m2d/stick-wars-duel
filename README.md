# Stick Wars: Duel ⚔️

لعبة استراتيجية 2D مستوحاة من ألعاب حروب العصا، مخصصة لمباراة بين لاعبين.

## ملفات المشروع
- `index.html` — واجهة اللعبة.
- `style.css` — التصميم المتجاوب للموبايل والكمبيوتر.
- `game.js` — منطق النسخة الأولية ومحرك Phaser.
- `server/` — سيرفر الغرف والاتصال اللحظي (Socket.IO).

## تشغيل الواجهة
يمكن نشر ملفات الجذر باستخدام GitHub Pages من إعدادات المستودع: **Settings → Pages → Deploy from a branch → main → /(root)**.

## تشغيل سيرفر اللعب
يجب نشر مجلد `server` على خدمة Node.js مثل Render، ثم وضع رابط السيرفر في خانة "رابط سيرفر اللعب" داخل اللعبة. GitHub Pages يستضيف الواجهة الثابتة فقط ولا يشغّل Node.js.

راجع `server/README.md` لإعداد السيرفر.

> هذه نسخة أولية قابلة للتطوير. توازن الوحدات والقتال والمزامنة ما زالت في مرحلة البناء.
